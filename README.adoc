= chocolatey-metanorma: Chocolatey package for Metanorma

The `metanorma` package on the https://community.chocolatey.org/packages/metanorma[Chocolatey community feed].

== What this package is

A *thin wrapper* around the signed Metanorma Windows installer. The nupkg
contains no Metanorma binaries — `tools/chocolateyInstall.ps1` downloads
`metanorma-setup-<version>-windows-ucrt64.msi` from the matching
https://github.com/metanorma/packed-metanorma/releases[packed-metanorma
release] at install time, verifies it against the SHA256 embedded in the
install script, and runs it silently (`/qn /norestart`).

== What the MSI does (the real work)

The MSI is built and Azure Trusted Signing-signed (CN=Ribose Limited) by
the packed-metanorma pipeline. On install it:

* installs Metanorma per-machine under Program Files,
* wires the `metanorma` command onto the system PATH,
* seeds the runtime into the machine-wide home, so the first run needs no
  downloads.

Uninstall is handled by Chocolatey's automatic uninstaller against the MSI
registration — there is no `chocolateyUninstall.ps1` to maintain.

== Releasing a new version

Everything is driven by the `main` workflow; nothing is released from a
developer machine:

. In GitHub, dispatch *Actions → main → Run workflow* with the Metanorma
  product version (e.g. `1.17.0`).
. The *build* job runs `build.ps1`, which finds the newest packed-metanorma
  release carrying `metanorma-setup-<version>-windows-ucrt64.msi` (the tag
  is not assumed to be `v<version>` — v1.17.0-1 ships the 1.17.0 MSI),
  downloads the MSI, computes its SHA256, renders `metanorma.nuspec` and
  `tools/chocolateyInstall.ps1`, and packs the nupkg.
. The *test* job installs the built nupkg from the local source on
  `windows-latest`, polls `metanorma --version` until it prints
  `Metanorma::Cli` (the first dispatch can take several minutes), then
  `choco uninstall`s and asserts removal.
. Only if the test passes, the *publish* job — gated by the
  `chocolatey-publish` environment — pushes the nupkg to chocolatey.org with
  the org-level `CHOCOLATEY_API_KEY` secret.

To build locally (requires `gh` and `choco`):

[source,powershell]
----
./build.ps1 -Version 1.17.0
----

== Moderation notes

* The package id is `metanorma`; the nuspec version tracks the Metanorma
  product version (1.17.0, …), not the packed-metanorma tag.
* A checksum is mandatory for community moderation: the MSI is verified
  with `checksum64`/`checksumType64` at install time. The nupkg never
  embeds the MSI.
* New versions land in the moderation queue after `choco push`; automated
  checks plus human review typically take hours to a few days before the
  version shows as approved on the feed. Users can install a
  not-yet-approved version explicitly with
  `choco install metanorma --version <version>`.
